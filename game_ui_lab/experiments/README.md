# Эксперименты — не активный интерфейс

- visuals/: новые изображения, варианты, пробы и сравнения художника.
- prototypes/: изолированные технические опыты.
- history/: прежние реализации и ассеты, сохранённые при замене.

Здесь можно готовить и проверять решения рядом с действующим интерфейсом.
В static/game/assets переносить только выбранные файлы, которые действительно
подключаются к текущему интерфейсу. Затем обновлять ссылки и manifest.
Не копировать все варианты в active assets и не создавать второй интерфейс.
