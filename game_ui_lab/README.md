## Запуск

Из корня проекта при готовом окружении `.venv` с Jinja2:

```powershell
./game_ui_lab/start.ps1
# Другой порт:
./game_ui_lab/start.ps1 -Port 8881
# Без PowerShell-скрипта:
.venv/Scripts/python.exe -B -m game_ui_lab.app --port 8879
```

Открыть http://127.0.0.1:8879/ . При открытой в редакторе папке самой Lab:

```powershell
./start.ps1
```

Сервер локальный. Настоящие Backend/БД/Redis/аккаунты для него не запускаются.
Данные и действия демонстрационные. Зависимости на чтение из основного репозитория
указаны в STRUCTURE.md; это не автономный архив. Lab и тесты разрешены для Git;
локальные мастера и пробы исключены в .gitignore лаборатории. Это не означает,
что файлы уже закоммичены или опубликованы.

## Проверка

Из корня проекта:

```powershell
.venv/Scripts/python.exe -m pytest tests/game_ui_lab -o addopts='' --no-cov -p no:cacheprovider -q
```

Для изменённого JavaScript проверить синтаксис, например:

```powershell
node --check game_ui_lab/static/game/core/boot.js
```

После правки открыть актуальную страницу, дождаться отрисовки и проверить её
взаимодействия/возврат. Для оболочки —1366×768,1920×1080 и предел1920 на широком
экране. Тесты не заменяют просмотр и решение владельца о внешнем виде.

Если редактор художника не подхватывает GEMINI.md автоматически, явно дать
агенту прочитать GEMINI.md и локальный SKILL.md перед поручением. Автозагрузка
конкретной средой в этой работе не проверялась.
