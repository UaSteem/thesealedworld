# Работа с Game UI Lab

Это существующий интерфейс, который нужно править на месте, а не заменять новым.

Перед изменениями прочитай:
1. [Локальный скилл](.agents/skills/game-ui-lab/SKILL.md).
2. [Текущие решения](docs/current-decisions.md).
3. [Карту файлов](STRUCTURE.md), затем только нужный компонент.

Выполняй конкретное поручение владельца/художника. Не переделывай соседние экраны, не выбирай дизайн за автора и не превращай обсуждаемые варианты в готовые функции. Новый интерфейс или новая оболочка требуют прямого поручения. Если контекст потерян — перечитай эти файлы и текущее задание.

Пробы изображений создавай в experiments/visuals/<задача>/; в активные assets переносится только используемое. Не исправляй дефект ассета скрытым костылём в коде без обсуждения. Основной runtime и Rift Lab не менять.

Запуск указан в README.md. После правки проверь именно изменённую страницу и возврат из неё; не называй непросмотренный экран проверенным.
