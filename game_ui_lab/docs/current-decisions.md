# Game UI Lab: текущие решения

Последняя сверка с владельцем: 2026-10-29. Это рабочий контракт дизайна, не доказательство готовности к production. Новое прямое поручение владельца имеет приоритет; после него обновить соответствующий пункт. Не объявлять принятое решение по одному лишь текущему коду.

## Принято для текущей работы

- Править существующий Game UI Lab. Скилл не разрешает перенос в основной runtime.
- Вся игровая область ограничена **1920 CSS px**, центрирована на широком экране. Удаление левой панели не отменяет этот предел. Высота следует доступному окну; не фиксировать1080.
- Постоянной левой панели нет. Слева сверху компактный аватар и HP/энергия/стамина; художественный вид ещё может меняться.
- Игровое поле занимает область под техническим хедером. Чат — HTML-overlay поверх поля снизу слева, без отдельной нижней полосы. Без hover/focus верхние строки затухают; при выборе/наведении читаемость восстанавливается. Около10 строк — ориентир примерки, не требование к каждому размеру.
- Хедер содержит **Debug и видимые кнопки всех страниц** для мгновенного доступа. Обычные цепочки переходов внутри сцен и возвратов сохраняются.
- Справа один блок **Персонаж / Квесты / Настройки**. В бою персонаж и инвентарь недоступны, включая клик на аватар и программные входы. Компоновка/иконки меню ещё не финальные.
- Персонаж — страница во всю игровую область. В снаряжении слева портрет/экипировка, справа предметы. В характеристиках портрет и экипировка не занимают колонку.
- Характеристики объединяют атрибуты, навыки и модификаторы. Навыки разделены по группам с раскрытием; закрытые — с замками, открытые — с процентами. Отдельных вкладок Навыки/Эффекты нет.
- Билды: плашка **не реализовано, под вопросом**, без фиктивного переключения сборок. Квесты — отдельная страница: узкий список со статусом слева, подробности выбранного задания справа. Настройки — отдельная страница; их состав пока не определён.
- Рифт здесь — фиксированный слепок для примерки интерфейса. Стартовый масштаб и предел отдаления временно **1.00×**. Debug регулирует минимальный масштаб (предел отдаления); галочка снимает его для разработчика. Это не ограничитель приближения.
- Сейчас лес A–J, пещера и земля1024×1024; исходные размеры2048/1280 сохранены в локальной резервной копии. Уменьшение до512 пока **не выполнено и не принято**: после уменьшения сравнить чёткость при1.00×.
- Пробы/варианты отдельно от активных ассетов; в active хранить только используемое.

## Только варианты для обсуждения

Тексты в `data/page-briefs.json` описывают намерения, не утверждённые механики.

- **Итог боя:** победа и смерть имеют близкую структуру, разные данные/результат/кнопки. Можно сохранить отдельную страницу или сделать интерактивную подачу поверх текущего **игрового поля**. Панель смерти с иконкой и кнопкой «В город» — пример, не принятое решение.
- **Добыча:** возможны отдельная страница, оформленное окно/сумка монстра либо перемещаемое окно примерно на60% поля. Выбор за автором интерфейса, затем обсуждается нужное поведение.
- **Город:** старый экран первой версии не является утверждённым новым городом. Карта мира/город ещё в работе; вероятное направление — игровое поле по типу рифта с кварталами.
- **Диалоги:** предпочтительны окна с выбором поверх поля; возможна композиция игрок слева/собеседник справа с аватарами, без HUD и меню поверх диалога. На мобильном может требоваться полный экран. Пробуждение — самостоятельная стартовая страница до остальной игры, **не первый квест**. Новое поведение пока не реализовано.
- Палитра Obsidian Bronze — текущая примерка, не финальный цвет. Дизайн не развивать самовольно из текста вариантов.

## Известные пробелы: не выдавать за готовое

- В слепке 9 атрибутов и41 навык текущего каталога, из них3 открыты в fixture. Это локальные данные, не живой персонаж.
- В игре30+ модификаторов, а в текущем JSON/экране лишь8 примерных параметров. **Полный состав ещё не подключён.** Автору нужен настоящий объём с группами/названиями/форматом значений. Не считать выборку полным слепком. Модификаторы не равны временным бафам.
- Отдельная ель512×512 под лесным массивомC — унаследованный обход дефекта ассета, который владелец оспорил. Он пока не устранён. Не принимать его за утверждённую архитектуру, не продолжать/размножать без обсуждения. Исправление исходного ассета требует отдельного поручения.
- Записанных диалогов квестов в fixture нет; честно показывается отсутствие данных. Настоящая механика получения добычи/возрождения не добавлена.
- Game UI Lab и её тесты разрешены для Git. Локальные мастера, пробы и старые картинки исключены через game_ui_lab/.gitignore; исторический JS, нужный тестам, сохраняется. Rift Lab остаётся локальной. Коммит и push не выполнялись.
- 16 изображений рифта и отрисовщик уже скопированы внутрь Lab; runtime-зависимости от папки Rift Lab нет. Но есть зависимости на чтение из основного репозитория: fonts/theme/Phaser/SVG/аватар, изображения предметов в assets/item_art/renders. Это не автономный архив и не проверка запуска из чистого checkout.
- Исторические тесты/скриншоты не доказывают текущее состояние. Проверка в Chrome не означает проверку актуальной пользовательской вкладки IAB; визуальная приёмка принадлежит владельцу.

## Текстуры: текущая примерка 1024
По решению владельца используемые текстуры рифта уменьшены пропорционально до максимума 1024 px; ель 512 не увеличена. Размещение на поле использует прежние reference-координаты, crop переводится в фактические пиксели изображения. Zoom 1.00 сохранён. Исходники лежат локально в tmp/game-ui-lab-rift-originals вне Git. Дальнейшее снижение до 512 не выполнено.
