Текущий режим R30 — подбор статичных пропорций на согласованном перспективном контуре30гексов. Крупный игрок слева ближе, крупная цель справа дальше; остальные участники уменьшены и вписаны в гексы. Изображения рисуются непосредственно из исходных текстур, целиком с сохранением пропорций, без промежуточных64pxкопий. Сверху только HPбезцифр. Подробности закрепляются/временно меняются при наведении в компактной панели верхнего левого угла. Анимаций и кнопок действий сейчас нет. Переключатель вида сверху/перспективы сохранён; данные демонстрационные, безWebSocket/API. Предыдущие разделы ниже описывают историю проб, не текущую спецификацию.

Изолированная локальная лаборатория игровых экранов. Запуск:

```powershell
.\.venv\Scripts\python.exe -m game_ui_lab.app
```

Адрес: http://127.0.0.1:8879/. Привязка только к127.0.0.1; параметр --port необязателен.

Текущая проба R18: конечное наклонное поле шириной5гексов на фоне RiftLab. Вертикальные карточки с полными исходными изображениями без обрезки стоят в подставках; над портретом только HP без цифр, потерянная часть серая. Подробности справа без дублирования изображения: наведение временно показывает участника, клик закрепляет его данные. Клик на врага также выбирает текущую цель. Кнопка «Демо размена» последовательно показывает потерю HP, уворот и промах.

Размер гекса зависит от ширины и высоты фрейма, не от количества участников. При недостатке высоты5рядов сменяются3компактными. Приоритет врагов: действовавшие против игрока, затем ближайший срок удара. Счётчики «Ещё +N» используют демонстрационные totals840/160; в памяти10fixtureучастников. Это не испытание настоящего боя на1000участников. Расширение на дополнительные ряды остаётся будущей пробой.

Большая HTMLпанель персонажа слева и локальный чат сохранены. Основные данные персонажа — fixture. Чат имеет локальный размер/сворачивание. Общая тема Adventure; Classic отключена.

Подключены standee-layout.js, map-scene.js, actor-details.js. Старые demo-model.js, battle-layout.js, scene.js сохранены отключёнными. Runtime/RiftLab/backend не меняются; нет API, WebSocket, авторизации, БД, Redis и наград. Общие статические assets обслуживаются из src/frontend/static. PROVENANCE.json хранит источники скопированных материалов. Детали и проверки — tasks/active/2026-10-24-game-ui-lab.md.

Уточнение R20: гексы увеличены; карточка и подставка помещаются внутри контура своего гекса. Изображения сохраняют исходные пропорции.

Уточнение R30: игрок смещён на соседний гекс левее; цель на13%меньше игрока; изображения врагов зеркально направлены к игроку. Союзники крупнее и у нижнего края. Очередь противников занимает два ряда без привязки ряда к готовности. Значки готовности, пульсация и WebSocket — будущая работа.

R31: вид «Сверху» — отдельное настольное оформление: карточки лежат на поле без подставок. Обычные участники одного размера относительно гекса, главная пара~1.5×. По умолчанию включён этот вид для оценки; перспектива доступна переключателем.

R36: сгенерированная основа боевого HUD подключена снизу справа. Таблица native-координат1942×809 — static/hud-layout.js; static/combat-hud.js рисует динамические иконки/текст/области клика одним контейнером. Все действия демонстрационные, реальные ресурсы не списываются. Меч остаётся при доступной новой цели; часы только при demoReadyfalse.
