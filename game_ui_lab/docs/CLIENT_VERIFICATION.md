# Проверки структурного переноса клиента

Изменения выполнялись только внутри Lab и его тестов. Production/runtime,
backend, каталоги игры и серверные данные не переносились и не менялись.

## До реализации

Три новых contract tests ожидаемо упали: не было новых core/scene/boot-путей,
общего shell и исполняемого каталога ассетов. Перед переносом инвентаря
отдельный contract test также упал на его старом module URL.

## После реализации

- `pytest tests/game_ui_lab game_ui_lab/test_inventory_app.py`: **27 passed**.
  Часть старых проверок относится к отключённым ранним опытам; текущую точку
  входа проверяют `test_client_structure.py` и реальные браузерные сценарии.
- JS placement/filter tests инвентаря: PASS для fixture,72 повторных и72 смешанных
  footprints; resize coordinator: PASS drag/release/coalescing/cleanup.
- Бой в браузере:1366×768,1600×900,1920×1080,2560×1440 — осмотр не меняет цель,
  accordion/wheel, сворачивание и восстановление состояния: PASS.
- Анимация размена и resize во время перехода:1920 и1366 — PASS.
- Повторный вход в боевую Scene×3: один канвас, один инспектор, без повторных
  запросов PNG/SVG и без HTTP-ошибок. Исправлена очистка ссылок/DOM-подписок.
- Inventory Lab после переноса:1920 и1366 — все6 текстур, открыть/закрыть,
  общий чат, без HTTP/JS-ошибок: PASS.
- SHA-256 пяти перемещённых PNG совпадают с прежними. Изображения не ресайзились.
- Asset audit:53 первоначальных локальных запроса,9 073 670 bytes файлов
  без HTML/HTTP headers. Browser observations включают дополнительный DPR2-профиль.

Проверка локальная. Это не независимый review, не замер VRAM/production latency
и не приёмка downscale. 512-экспорты, production cache, реальный backend adapter
и общий переход бой↔инвентарь пока не реализованы.
