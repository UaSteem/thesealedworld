# Граница фронтенда и моков: проверка 2026-10-29

## Решение владельца

Lab — самостоятельный прототип будущего фронтенда. Он не обязан повторять текущий frontend src. Собственные сцены/контроллеры интерфейса допустимы; backend-код и копии backend-алгоритмов запрещены. Ответы backend имитируются fixtures/mock-адаптером. Прежний вывод об обязательном подключении клиента src был ошибочной трактовкой исполнителя. Runtime не менялся.

## Вывод и дальнейшая работа

В проверенных активных файлах не выявлены импорты backend-сервисов, генератор рифта или боевой resolver. Сцены и renderer — код представления. Локальная арифметика mockWeight и подстановка типа/веса — демонстрационные данные; это не доказательство копирования backend-алгоритма. При развитии моков лучше хранить готовые значения ответа и не превращать демонстрацию в собственные игровые расчёты.

Обязательной миграции Lab на текущий frontend src нет. При будущем подключении backend нужно сверить форматы и сценарии ответов/ошибок. Неполный каталог модификаторов остаётся отдельным известным пробелом.

Проверка статическая: активные app/fixtures/templates/static/game и сравнение src inventory. Полный аудит src, настоящий backend и mock/real взаимозаменяемость не проверялись. Независимый ревизор не подключался по выбору владельца.
