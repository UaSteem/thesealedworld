# Базовая семья крыс

PNG с прозрачностью, чистые тёмные контуры, сдержанная угловатая светотень,
крупные формы серо-коричневой шерсти. Референс: png/sewer_rat-v1.png.
Крысиная анатомия: вытянутая морда, резцы, округлые уши, четыре лапы и голый длинный хвост.
Названия выражают характер, роль или телосложение. Болезнь, яд и стихии — вариации кланов.

Адаптация ассетов к новой логике:
plague_rat -> burrow_guard (Страж норы)
rotfang -> ironfang (Железный клык)
blight_carrier -> heavy_rat (Крыса-тяжеловес)
Крысиный король — живой клубок крыс; две крысы выбираются из него, обыгрывая призыв.
Готовый Python-каталог использует новые имена; старые записи в базе сохранены. catalog_variant_id сохраняет происхождение.
Принятый набор — v2 (12 изображений).
