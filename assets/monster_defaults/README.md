# Дефолтные изображения монстров для разработки

Здесь постепенно собираем SVG для всех семей. Одна картинка на вариант монстра.

Структура: `<family_id>/master_prompt.txt`, `prompts/<variant_id>.txt`,
`svg/<variant_id>.svg`, `manifest.json`. Общий список описаний: `PROMPTS.md`.

Начали с goblin_tribe: goblin_sneak принят пользователем как образец стиля.
Его SVG сохранён без изменения байтов. Остальные 11 изображений ожидают генерации.
Описание каждого персонажа основано на текущем каталоге; поза и выразительность — художественная интерпретация.

Порядок: мастер-промпт и SVG-референс, затем одно описание за генерацию.
Результат сохраняем под точным variant_id, проверяем и меняем статус в manifest.json.

Целевая интеграция (пока не реализована): в режиме разработки выбирать постоянный
SVG по family_id + variant_id, независимо от имени, описания, visual_hint и хеша
генерируемого контента. Для отсутствующего SVG использовать семейную заглушку.
Текстовые описания могут обновляться; изображение остаётся тем же.
Запросы генерации изображений в этом режиме должны отключаться отдельно от
генерации текста, включая ручную регенерацию и постановку задач в очередь.

Текущие runtime-заглушки находятся в src/frontend/static/images/monsters/families;
эта папка — сборник исходников, пока не подключённый к runtime.
Следующие семьи: rat_swarm, wolf_pack, bandit_gang; системные anchor_sovereigns отдельно.

## Решение о базовой семье (12.10.2026)

Собранные персонажи предназначены для полноценной самой простой семьи гоблинов,
а не только как визуальный шаблон генерации. Тематические семьи могут использовать
её как основу. Это согласованное направление; материализация семьи в базе данных
и подключение статичных изображений к runtime пока не выполнены.
