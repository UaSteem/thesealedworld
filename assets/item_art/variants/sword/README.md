# Одноручный меч: пробные варианты T0–T5

Одна очищенная вертикальная основа `../../svg/sword.svg`, база каталога `sword`.
T1 сохраняет исходную палитру. T0 — изношенный металл с ржавчиной и старой обмоткой.
T2–T5 используют художественные палитры материалов из текущего каталога Items.

| Тир материала | Материал | ID |
| --- | --- | --- |
| T0 | Ржавый лом | `mat_scrap_metal` |
| T1 | Железо | `mat_iron_ingot` |
| T2 | Кобальт | `mat_cobalt_ingot` |
| T3 | Мифрил | `mat_mithril_ingot` |
| T4 | Адамантит | `mat_adamantite_ingot` |
| T5 | Торий | `mat_thorium_ingot` |

Силуэт, ракурс и базовые контуры одинаковые. Кожа рукояти T1–T5 сохранена.
Тени и блики металла сохранены через палитры градиентов. Части меча объединены в именованные группы.
Цвета — пробное художественное решение, ещё не принятые финальные палитры.
`variants.json` — рабочее описание набора ассетов, не runtime-источник.
Оригинальный Arrow SVG и общая очищенная заготовка не менялись.

Подготовлены Python-определения и Pydantic-модели в Items:
[`resources/visuals/`](../../../../src/backend/features/items/resources/visuals/).
Порядок поиска и явной проверки описан в [документации](../../../../docs/ru/backend/features/items/visual_catalog.md).
JSON остаётся рабочим описанием ассетов; Python-каталог его не загружает.
Генератор выбирает вариант и сохраняет его ID у экземпляра. Публичный bootstrap и инвентарь используют два размера из S3.
`delivery-preview.png` сравнивает миниатюры экипировки и инвентарные виды всех шести тиров.
WebP находятся в `../../renders/`; Python-описание S3-ключей — `resources/visuals/sword_renders.py` внутри Items.
Сборка и публикация: `python -m tools.assets.item_visuals build`, затем `python -m tools.assets.item_visuals publish`.
