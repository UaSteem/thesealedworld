# Изображения предметов

- **`svg/` — рабочая папка.** Здесь все 16 очищенных SVG: без фоновых плашек и посторонних фигур. Меч вертикальный.
- **`originals/` — оригиналы Arrow.** Сохранены побайтно; не редактировать.
- **`preview.png` — актуальный обзор** рабочих SVG на одном фоне.
- **`manifest.json` — список ассетов:** имя, путь оригинала и рабочей копии, контрольные суммы и выполненная очистка.
- **`archive/` — прежняя раскладка, дубли и старые превью.** Для текущей работы не нужна.

Новый SVG сохраняем в `originals/`; очищенную копию с тем же именем — в `svg/`. Превью строим только из `svg/`.
Первый набор вариантов: [одноручный меч T0–T5](variants/sword/README.md). Остальные заготовки ещё не размечены по материалам.
Для меча подготовлены два размера WebP в `renders/`, публикация в S3 и выбор при генерации.
Оба варианта перчаток — одежда кистей, не наручи. Простые перчатки (`work_gloves.svg`) остаются на рассмотрении.
Рубаха и туника используют одну визуальную основу. Для меча зафиксирована база `sword`; остальные связи с ID каталога пока не назначены.

Согласованная схема будущего выбора изображений: [база → набор вариантов → выбор по тиру, материалу и аффиксам → сохранение варианта в предмете](../../docs/adr/0001-item-visual-selection.md).
Для меча T0–T5 подготовлен [Python-каталог с Pydantic-моделями](../../docs/ru/backend/features/items/visual_catalog.md).
Выбор изображения и сохранение варианта реализованы в исходниках. Применение миграции к рабочей БД и развёртывание не выполнялись.
