# Services

> Раздел в разработке.

- [Контракт исполнения действий внутри размена](exchange_execution.md)
- `CombatResultArchiveService` при отсутствии горячей финализации восстанавливает
  краткий результат из фактических полей SQL-записи и проверяет участие персонажа.
  При отсутствии команд в краткой записи исход отдельного участника PvP остаётся
  неизвестным; агрегатный `player_win` не подменяет принадлежность к победившей команде.
