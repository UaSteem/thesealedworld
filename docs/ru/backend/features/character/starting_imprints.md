# Стартовые слепки

Рабочий каталог: `src/backend/features/character/resources/starting_imprints.py`.
`StartingImprintService.available_keys()` возвращает 14 допустимых сочетаний:
4 щитовика, 6 двуручников, 2 фехтовальщика с парным оружием, 2 лучника.
Смешанные пары меч/кинжал и булава/дага исключены. Два меча и две булавы
не добавлены: каталог предметов запрещает их вторую руку.

У каждого слепка 135 базовых атрибутов, разрыв максимум8; внутри физической,
магической и сенсорной троек значения различны. Навыки: оружейный10%,
тактический7.5%, соответствующая броня5%. Два клинка имеют выносливость15;
луки используют последнюю согласованную правку ловкости−1, выносливости−1,
проекции+2 относительно исходного тестового набора.

Предметы Т0 без аффиксов: оружейный комплект, нагрудник соответствующего типа,
льняная рубаха, меховые штаны, дорожные сапоги и пояс. У луков разные колчаны.
Предметные определения, стоимость и боевые формулы не меняются.

Новые персонажи получают слепок через существующую материализацию GameLobby;
выбор случайного слепка использует новый каталог. Текущие персонажи не
перераспределяются и не переодеваются. Миграции данных не требуется.
Студия и симулятор получают список из того же каталога. После обновления
долго работающих процессов требуется обычная перезагрузка кода приложения.

`var/starter-reference-t0` — сохранённый контрольный артефакт, а не источник
данных игры. Производственный код не читает файлы из var. Последние варианты
луков ещё не прошли новый боевой прогон; это принятое состояние для дальнейшей
работы над семьями, без заявления о завершённом балансе.
