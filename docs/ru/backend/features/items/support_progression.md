# Прогрессия базовых бонусов экипировки

R47 заменяет ориентир R46 «прирост 20→22–23» на полный вклад одной
характеристики 0→20 при нулевых support skills. Сравнивается одно свойство,
а не весь набор свойств характеристики.

Источник значений — `resources/support_progression.py`. Для восьми выбранных
implicit характеристик и отдельного бонуса crit перчаток используется геометрическая прогрессия:

`raw(tier) = T0 * (T7 / T0) ** (tier / 7)`

R49 округляет фактический механический результат после этой формулы:
HP/stamina до целого, regen/initiative до десятых, вероятности до 0.001
внутренней доли (0.1 процентного пункта). Опорные точки формулы сохранены;
сравнение с эталоном характеристики выполняется с тем же округлением.
Например, initiative T0 теперь 0.6, HP T7 — 109, stamina T7 — 127.
Quick slots остаются целыми по прежней схеме 1–8.

| База | Свойство | Опорный T0 до округления | Опорный T7 до округления | Эталонная характеристика |
| --- | --- | ---: | ---: | --- |
| belt | hp | 8 | 109.0909 | endurance |
| boots | stamina | 8 | 127.2727 | projection |
| boots | stamina_regen | 1.2 | 10.9091 | projection |
| gloves | anti_dodge_chance | 0.032 | 1.0909 | perception |
| gloves | physical_crit_chance | 0.008 | 0.20 | явный бонус20% |
| cloak | hp_regen | 0.4 | 4.1819 | endurance |
| ring | mental_resistance | 0.024 | 0.7273 | mental |
| amulet | en_regen | 0.8 | 9.0909 | mental |
| earring | initiative | 0.56 | 18.1818 | agility |

Опорный T0 зафиксирован по фактической генерации R46; результат округляется по R49. Все разрешённые семейства
материалов одной базы имеют одинаковые опорные точки; между ними нет второго
множителя мощности. До округления абсолютная прибавка растёт к старшим тирам; после округления допускаются равные соседние приросты. Тесты сверяют
T7 с текущим `StatsWaterfallCalculator`, а все T0–T7 — с формулой выше.

Эталон stamina_regen исключает общий базовый regen=1. Эталон hp_regen включает
естественную регенерацию от HP endurance. Для en_regen сравнивается outside
вклад: combat-вклад характеристики у игрока равен нулю. Прямой бонус предмета
en_regen продолжает действовать по существующей общей проекции.

Это узкое исключение из обычного правила `implicit * material.tier_mult`.
R48 задаёт crit перчаток отдельно: T7 даёт +0.20 к глобальному шансу,
независимо от оружейного мастерства; T0 сохраняет +0.008. Это не увеличение
crit damage и не гарантия крита. Мастерство умножает только базовый crit
активной руки: `hand_crit * (1 + skill) + global_crit`, затем применяется
прежний cap. Магические и item ветки не используют множитель оружейного
мастерства; elemental выбор источника и trigger hooks сохранены.
R49 удаляет innate environment_gravity_resistance обуви,
environment_bio_resistance перчаток, environment_cold_resistance плаща и
debuff_avoidance амулета из каталога и runtime-проекции сохранённых implicit.
Аффиксы с такими свойствами сохраняются. Вместимость пояса, durability,
оружие, броня, аффиксы и каталог материалов сохраняют прежние правила.

`implicit_bonuses_base` сохраняет исходные авторские значения шаблона. Для
выбранных девяти параметров это не T0 и не множитель кривой: опорные точки
задаются явно в `SUPPORT_PROGRESSION`. Factory и runtime projection используют
один чистый расчёт, без повторного умножения или накопления бонуса.

При чтении сохранённого предмета порядок определения тира:

1. `mechanics.material.tier`;
2. тир материала из каталога по material ID;
3. `mechanics.tier`, `metadata.tier`, `item.item_tier`,
   `generation.item_tier`, `mechanics.item_tier`;
4. T0 при отсутствии сведений о тире.

Нельзя выводить тир из `tier_mult` или `rarity_tier`. Не конечный или дробный
тир отклоняется с `ValueError`; конечный целый ограничивается диапазоном0–7.
Runtime меняет только явно принадлежащие базе параметры, сохраняет остальные
implicit и affixes и не изменяет исходный словарь. Удалённые базовые HP regen
кольца и stamina regen серьги не восстанавливаются. Это проекция, без записи
или миграции сохранённых данных.
