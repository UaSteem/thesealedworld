# Големы: предварительная настройка альфы

Переносимые итоговые настройки, результаты и поддерживаемая команда запуска: [сводка альфы](alpha_acceptance.md). Упомянутые ниже пути `var` — необязательные локальные материалы; отменённые серии сохранены в проверенном архиве истории.

Доступны с Т2. Встроенный общий предел для профилей только с миньонами — 2–3 бойца; если разрешён хотя бы один старший ранг — 1–2 бойца, включая миньонов. Условие определяется разрешёнными рангами профиля, не названием встречи. Внешние профили задают собственные ограничения. Два независимых пула сохранены.

Цены миньонов: `stone_thrower` 13, `stone_worker` 14, `stone_sentry` 15, `stone_ram` 16. Ветераны 23, элита 30, боссы 45. После настройки цен и границ отряда восемь старших получили пробное увеличение суммарных базовых атрибутов на 10% с целочисленным округлением half-up и распределением остатка по наибольшим дробным частям (при равенстве — порядок атрибутов). Четыре миньона не усилены. Навыки, оружие, способности, изображения и общая тирная кривая сохранены. 48 активных природных комплектов / 176 предметов остались без изменений.

Старый каталог отклонил все 480 заказов: недостаточный бюджет. После настройки тот же тяжёлый щитовик получил 480 отрядов без отказов, размер 2–3; минимальный фактический пул миньонов 30, дешёвая пара стоит 26. Это проверка конкретных контрольных профилей, не гарантия сборки при произвольном GS.

Исторический пилот с пределом 2–3: Т2–Т5, четыре типа встреч, три сложности, по 10 seed — 480 боёв. После уточнения владельца предел исправлен на 1–2; боевые проценты ниже относятся к прежним составам и не подтверждают баланс нового предела. Игроки совпадают с предыдущими сериями; без бонусов симбиота, Анатомия ограничена 50%, финты у обеих сторон. В пилоте источник был стабилен, все проверки пройдены. Старых боёв для парного сравнения нет: ранее все заказы отклонялись.

Артефакты: пилот (`var/golem-alpha-priced-pilot/report.html`, локальный материал), границы изменений и проверка сборки (`var/golem-alpha-candidate/candidate.json`, локальный материал), исходный аудит (`var/golem-alpha-inventory/REPORT.md`, локальный материал), старый допуск (`var/golem-alpha-baseline/report.html`, локальный материал). Проверки реализации: 143 целевых теста и Ruff; активные комплекты проверены на готовность. БД и Combat не изменялись.


Уточнение 19.10.2026: профили только миньонов 2–3, со старшими 1–2. Базовые суммы старших до → после: ветераны 131→144, 142→156, 146→161; элита 180→198, 181→199, 194→213; боссы 230→253, 201→221. Это пробное усиление, не подтверждение целевых боевых процентов. Исторические таблицы выше относятся к старому составу и прежней силе. Доказательства неизменности остальных полей и проверка 480 заказов находятся в `var/golem-alpha-split-seniors/candidate.json`.
