# 🔄 Игровые циклы и Режимы (Game Loops)

## 1. Основной цикл выживания
Геймплей строится на повторяющемся цикле подготовки и вылазок: **Город (Подготовка) → Открытый Мир (Путь) → Разлом (Цель) → Город (Награда/Синхронизация).**

## 2. Режим: Экспедиция (Открытый мир)
Это основное состояние перемещения по глобальной карте.

*   **Цель:** Перемещение между ключевыми точками (города, места интереса, входы в Разломы).
*   **События:** Случайные встречи (торговцы, монстры, лорные объекты «Эхо»).
*   **Автопилот:** При движении по уже открытым маршрутам Симбиот берет на себя рутину, но риск засады сохраняется.

## 3. Режим: Разлом (The Rift)
Это основной PvE-контент. Разломы — это «осколки» других реальностей, врезавшиеся в наш мир.

*   **Структура:** Внутри Разлом представляет собой Граф Нод (Комнат).
*   **Геймплей:** Игрок не ходит по клеткам, а выбирает следующую точку интереса (Бой, Ловушка, Сокровище, Костер).
*   **Прогрессия:** Только в Разломах можно добыть Осколки для развития Симбиота и Дара.

## 4. Режим: Хаб и Городская жизнь
Мирные активности в городах фракций и других предусмотренных безопасных зонах.

*   **Подготовка:** Крафт, ремонт, торговля.
*   **AFK-прокачка:** Тренировка навыков на манекенах или фоновое производство ресурсов.
*   **Развитие города:** Совместные проекты строительства кварталов и развитие их внутреннего наполнения. См. [ADR-0002](../../../adr/0002-faction-city-district-progression.md). Это направление будущего развития, а не заявление о работающей городской экономике.
