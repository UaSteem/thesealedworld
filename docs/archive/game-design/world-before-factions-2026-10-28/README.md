# Исторические материалы до очистки лора 28.10.2026

Эти копии сохранены для истории перед изменением актуальной документации.
Они НЕ являются источником действующего лора или технических требований.
Модель одного центрального города и четырёх Якорей отменена владельцем для актуальных материалов.
Ссылки внутри копий сохранены как в оригиналах и не являются навигацией по архиву.

Текущие источники: `docs/game-design/designer/world/README.md` и ADR-0002.
Снимок также содержит документы со смешанным содержимым, из которых убраны зависимые формулировки; это не означает отмену всех сохранённых в них механик.
