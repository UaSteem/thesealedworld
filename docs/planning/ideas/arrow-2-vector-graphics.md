## Идея
Попробовать QuiverAI Arrow 2 (часто называют Arrow 2.0; API model ID: arrow-2) для игровых SVG-иконок: предметы, способности, статусы, ресурсы, классовые эмблемы и элементы интерфейса.

## Подтверждённые возможности
Модель создаёт редактируемые SVG по тексту и референсам, векторизует растровые изображения, редактирует SVG и поддерживает SVG-анимацию. Поддерживает до 14 изображений-референсов. Arrow 2 Telos предлагается для сложной детализированной графики; начинать с обычной Arrow 2.
Источники: https://quiver.ai/models/arrow-2 и https://docs.quiver.ai/developers/models/image-to-svg

## Предварительная оценка
Хороший кандидат для исследования: собственный SVG-выход позволяет править формы и цвета и масштабировать графику. Практическая пригодность для нашей игры пока не доказана. Демонстрации производителя не заменяют тест набора иконок в интерфейсе.

Проверить читаемость в малом размере, единый стиль всей серии, объём и сложность SVG, трудозатраты ручной доводки и отображение в выбранном игровом рендерере. Поддержку SVG-фильтров и анимаций нельзя считать гарантированной без проверки используемого движка.

Официальный гайд рекомендует повторно использовать один промпт, фиксируя размер, геометрию, отступы, палитру и толщину линий; менять только предмет. Сам гайд перечисляет возможные проблемы: лишние детали, несогласованный стиль, слабая векторизация и изменения лишних элементов при редактировании.
Источник: https://docs.quiver.ai/app/prompt-guide

## Предлагаемый тест
1. Сделать 10 иконок: меч, щит, лук, посох, зелье, золото, огонь, лёд, яд, оглушение.
2. Зафиксировать одну палитру, ракурс, толщину обводки, viewBox и прозрачный фон; использовать одну утверждённую иконку как референс стиля.
3. Сравнить при 24, 32 и 64 px на светлом и тёмном фоне.
4. Записать стоимость всех попыток, время генерации, размер файлов и минуты ручной доводки.
5. Проверить SVG в реальном интерфейсе игры. Выбирать инструмент по качеству готовой серии и затратам на её доводку.

Приложение: Go $8/месяц, Basic $20, Pro $40. API оплачивается отдельно от подписки приложения.
