# Вложенные каталоги стартовых семей

Четыре обычные семьи используют `catalog/nested_contracts.py`. Их независимые пакеты:

- `families/wolf_catalog/` — 11 типов;
- `families/rat_catalog/` — 12 типов;
- `families/goblin_catalog/` — 12 типов;
- `families/bandit_catalog/` — 12 типов.

В каждом пакете `bases/` хранит общие механические основы, `clans/base/members/` — конкретные варианты с именами, описаниями, тегами, изображениями и явными наборами навыков/способностей. `clans/base/clan.py` собирает состав, `family.py` собирает вложенный DTO семьи. Статы не копируются в файл кланового варианта.

Перенос сохраняет текущие ID, порядок, числовые характеристики, экипировку, навыки, описание, теги, арты и настройки спавна. `base_id` показывает общую основу; `ability_ids` пока пустые. Новые способности и их исполнение в Combat не добавляются этим переносом.

Системные владыки якорей остаются в прежнем формате, исключены из обычного спавна. Исторические исходные словари и записи БД сохранены. Новые пакеты не импортируют старые словари при загрузке каталога.

Проверка: сравнение полного результата до/после, запрет загрузки исторических ресурсов активным каталогом, повторное использование основ с независимыми вариантами, API/Studio без доступа к БД.
