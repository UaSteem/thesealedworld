# Общие карточки предметов

Студия и будущая библиотека используют одно представление предмета.

- Items владеет `ItemCardDTO` и сервисом преобразования runtime-проекции: названия, описания, единицы измерения и эффекты.
- Общий HTTP-контракт клиента: `src/frontend/integrations/backend_api/item_presentation.py`.
- Шаблон: `src/fastapi_cabinet/templates/components/items/card.html`, вход — переменная `card`.
- Независимые стили: `src/fastapi_cabinet/static/css/item-card.css`; контейнер — `.item-card-grid`. Цвета переопределяются через `--item-*`.

Шаблон не вычисляет характеристики и не обращается к каталогу. Для использования в библиотеке подключить этот шаблон через Jinja loader общего пакета cabinet и его таблицу стилей. Backend библиотеки возвращает тот же DTO; зависимость от Studio не нужна.

Читаемые свойства и бонусы показаны сразу. Исходные ID, команды модификаторов, аффиксы, параметры генерации и полная runtime-проекция доступны в закрытом по умолчанию `details` «Технические данные». Поле `technical` не предназначено для публичного ответа библиотеки: публичный endpoint должен исключить его из ответа, если отладочная информация не нужна.

Представление не изменяет готовые предметы, характеристики монстров или данные БД.
