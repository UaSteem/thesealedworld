# Вложенный каталог волков

Волки — первая семья с отдельной общей основой бойца и конкретным клановым вариантом. Данные находятся в `src/backend/features/monsters/catalog/families/wolf_catalog/`.

- `bases/`: неизменяемые определения роли, характеристик, снаряжения, доступных тиров и веса спавна.
- `clans/base/members/`: имя, описание, теги, ссылка `base_id`, арт, явный список навыков и отдельный `ability_ids`.
- `clans/base/clan.py`: состав и общие свойства базовой стаи.
- `family.py`: сборка семьи из основ и кланов.
- `catalog/nested_contracts.py`: типизированные вложенные DTO и проверка/раскрытие ссылок.

Новый вариант ссылается непосредственно на общую основу; цепочек наследования нет. Основу нельзя изменить через вариант. Навыки и способности задаются явно и независимо; способности не подменяют `skills`. Для текущей стаи `ability_ids` пусты — новые игровые способности не добавлялись, исполнение их в Combat не входит в этот этап.

Для существующих потребителей определения раскрываются в `FamilyDefinition`, `ClanDefinition`, `MemberDefinition`. API сохраняет прежние поля и добавляет `base_id` и `ability_ids`; Studio показывает источник характеристик и список способностей.

Исторические ресурсы и записи БД остаются сохранены. Активный каталог волков больше не копирует старый словарь при загрузке. Остальные семьи пока используют прежний путь подготовки.

Сверка всех 11 волков со снимком до миграции: ID, порядок, имя, описание, теги, арт и все механические поля совпадают.
