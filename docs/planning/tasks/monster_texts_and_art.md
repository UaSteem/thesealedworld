# Тексты и дефолтные арты монстров

Четыре обычные семьи, их базовые кланы и47бойцов используют собственные RU тексты из `catalog/resources/texts.py`, связанные через `text_id`. Якорные определения оставлены в историческом виде. Старые сгенерированные описания в новые ресурсы не импортируются.

## Языки

`LANGUAGE_TEXTS` — данные по языкам. Для перевода добавьте ключ языка с переводами существующих text_id; механика и ID не меняются. `catalog/texts.py` выбирает запрошенную локаль, затем базовый язык (de-DE → de), затем обязательный ru. Неизвестный text_id и отсутствие русского оригинала — ошибки каталога. Частичный перевод допустим, незаполненные записи используют ru.

Bootstrap и инспекция принимают `locale`; ответ содержит сведения о выбранном тексте и fallback. Bootstrap schema_version=2, версия/ETag учитывают язык и содержимое. Пока написаны только русские тексты; наличие механизма не означает, что английский перевод уже создан. Навыки/предметы сохраняют собственные прежние форматы — глобальный перевод всей игры этой задачей не внедрён.

## Изображения

`MemberBaseDTO.default_image` хранит дефолт. `MemberVariantDTO.image` — необязательный уникальный арт. В `resolve_family` выбирается уникальный арт варианта, иначе дефолт основы. В результате `image` — уже выбранный арт, `image_source` — variant_override/default_base или null при отсутствии. API, bootstrap и Studio используют этот результат.

Все47принятых изображений назначены дефолтами соответствующих основ. Новые картинки не заказывались. Параметры отображения и asset_id сохранены.

## Механика

Характеристики, fixed_loadout, навыки, роли, spawn_weight и диапазоны тиров не менялись. Тирная подготовка — отдельный следующий слой; проект решения описан в `monster_tier_projection_design.md`. Старый runtime остаётся отключён, БД этой задачей не меняется.
