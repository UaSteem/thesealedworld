# Улучшение знаний и проверок

Для каждой установленной первопричины спроси, проявился ли повторяемый пробел в правилах или проверках. Разделяй предложения:

Оцени применимость для project rules, backend, security, quality/testing, deployment/release, затронутого domain skill, архитектурных validators и CI gates; для ненужного изменения укажи «не требуется» с причиной. Разовый дефект может оправдывать regression test (Enforcement), даже если Knowledge и Workflow менять не нужно. Для общего правила нужна повторяемая причина или доказанный устойчивый контракт.

| Тип | Вопрос | Куда направить |
| --- | --- | --- |
| Knowledge | Какой устойчивый контракт агенту нужно знать? | [project](../../turnbasedmmorpg-project/SKILL.md) или профильный domain skill. |
| Workflow | Какую проверку следует выполнять при похожей разработке? | [quality](../../turnbasedmmorpg-quality/SKILL.md), профильный skill или [release](../../turnbasedmmorpg-release/SKILL.md) по стадии/деплою. |
| Enforcement | Какая проверка должна ловить нарушение независимо от агента? | Предложение к тестам, архитектурному validator или CI gate с измеримым сигналом и границами ложных срабатываний. |

Отдельного project security skill сейчас нет. Для **нового явно запрошенного security review** используй установленный глобальный `security-review`; при разборе существующей security-находки маршрутизируй к владельцу затронутого контракта и оцени, нужен ли повторяемый security-контроль. Не создавай новый security-аудит или skill по инерции.

Проверяй существующие правила и gates до предложения новых. Несколько незащищённых API-маршрутов могут обосновать общее правило permissions и автоматическую проверку. Одиночная ошибка индекса MongoDB обычно требует исправления и regression test; глобальное правило нужно только при доказанном системном пробеле. Помечай каждое улучшение как предложение, связывай с root cause и доказательством повторяемости. Изменения других skills, tests, CI и validators выполняются только после отдельного разрешения; уже данное явное разрешение сохраняется.
