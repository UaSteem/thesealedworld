# Отключение записи монстров из Studio

По решению владельца Studio оставляет только просмотр и инспекцию монстров.

Снимки `.snapshot` сохраняют предыдущую реализацию; исходные пути и SHA-256 указаны в `manifest.json`. Удалены Studio routes/handlers `monster-rebuild-plan`, `monster-rebuild-apply`, страница и пункт обслуживания, клиентские методы POST пересборки и шаблон её формы. Каталог, фильтры, карточки, визуальные данные и исторические статусы задач остаются доступными для чтения.

Backend API пересборки не менялось. Его права будут отдельной задачей. Остальные инструменты Studio, в том числе тестирование боевого ИИ, этой правкой не затронуты. Реальные данные и хранилища не использовались.

Проверки: 25 тестов Studio content_ops и backend monster routes прошли; Ruff и diff whitespace прошли. В тестах старые записывающие маршруты отвергаются до обращения к backend независимо от cookie выбранного источника local/prod. Проверены сохранённые страницы инспекции и счётчики изображений.
