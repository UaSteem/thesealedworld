# Архив API-генерации монстров

Дата: 2026-10-14. Сохранены снимки исходников перед отключением API-заказа текстов и изображений монстров, включая экспериментальные Quiver CLI. `manifest.json` содержит исходные пути и SHA-256 каждого снимка. Расширение `.snapshot` исключает обычный импорт Python, исполнение CLI и сбор архивных тестов pytest. Для смешанных модулей сохранён исходный файл целиком; действующая версия остаётся в `src/`.

Архив справочный. Возвращение этой реализации потребует отдельного решения, восстановления зависимостей и новых проверок. Секреты, `.env`, реальные БД и изображения в архив не копировались.

## Выполненная очистка

- Удалены monster handlers из общего registry, services заказа flavor/изображений, prompts и CLI-перегенерация.
- Сборщик клана больше не получает GenerationAIService и не ставит flavor-задачу. Сохранены программный расчёт бойцов, загрузка готового flavor, habitat pools, сборка группы и существующие ID.
- Убраны четыре backend-маршрута и четыре действия Studio, клиентские вызовы и кнопки заказа.
- Активные visual helpers строят только статические ссылки. Промпты, модель, storage targets для будущего API-заказа удалены. Отображение старых сохранённых generated URLs, cache versioning и чтение исторических статусов сохранены.
- При получении worker старой задачи ровно одного из типов `monster.clan_flavor`, `monster.clan_image`, `monster.member_image` задача становится `failed` с причиной `RetiredTaskType`, без вызова провайдера и без повторной попытки. Новые запросы этих типов отклоняются как незарегистрированные.
- Registry, провайдеры, очереди и обработчики предметов, мира и новостей сохранены. Их retry policy не менялась.

## Данные и границы

Последующее решение 2026-10-14: записывающие действия пересборки монстров также удалены из Studio; см. `archive/studio_monster_writes/2026-10-14/README.md`. Backend-пересборка остаётся отдельной служебной поверхностью; её права пока не менялись.

Доступа к реальным хранилищам не было: SQL/Mongo-строки, старые generated assets и общая очередь не удалялись. `catalog_inventory.json` фиксирует только текущие ресурсные ID пяти семей и четыре исходных asset manifests; это не выгрузка кланов из БД.

Старые поставленные задачи завершаются указанным способом только при получении их обновлённым worker. Уже исполняющаяся в старом процессе задача этим изменением не прерывается. При применении изменения требуется согласованное обновление backend и worker; задача, вообще не попавшая в очередь, сама не восстановится. Массовая отмена, очистка очередей и исправление общей recovery-проблемы не выполнялись.

Принятые арты в `assets/monster_defaults/` сохранены без изменений. Их публикация и импорт базовых кланов в БД ещё не выполнялись. Для новых программно построенных шаблонов пока сохранены существующие семейные static placeholders; ранее сохранённые картинки продолжают читаться. Богатый подбор нового авторского каталога по тегам остаётся следующим этапом; действующий выбор по habitat pools сохранён.

## Проверки

Локальный прогон: 281 тест монстров, GenerationAI, предметов, мира и кабинета прошёл. Исключён существующий `tests/backend/features/generation_ai/test_asset_backfill.py`: он импортирует отсутствующий пакет `scripts`, удалённый до этой работы. Coverage для ограниченного прогона отключён; глобальная политика не менялась.

Windows sandbox блокировал loopback socket при создании asyncio event loop; успешный прогон сделан с разрешённым локальным запуском вне этой блокировки. Платные API-запросы, production и реальные БД не использовались.

Проверка Ruff затронутых активных Python-файлов, отсутствие активных импортов удалённых handlers/CLI, контроль snapshot hashes и scoped diff whitespace — выполнены. Оставшиеся исторические audit IDs не объявлены закрытыми целиком: остальные потребители GenerationAI продолжают действовать.
