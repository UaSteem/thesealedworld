# Предыдущая подготовка снаряжения гоблинов

Исторический снимок перед переходом на общий каталог предметов: 72 комплекта, 282 назначения, старый инструмент подготовки. Это архив исходных файлов, не экспорт базы данных.

Активный загрузчик использует ссылки из `goblin_catalog/equipment/references.py` на `catalog/equipment_library`. Архив не импортируется и не служит резервным источником. Старый скрипт сохранён как свидетельство прежнего способа подготовки; запускать его для актуального каталога не следует.
