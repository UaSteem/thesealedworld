# Архив данных, выведенных или подготавливаемых к выводу из игры

Это постоянная точка входа для локальных архивных данных проекта. Не смешивать с архивными снимками исходного кода в соседних папках archive. Архивы пока не сжимаются.

Начните с [INDEX.md](INDEX.md). Каждый снимок находится в `snapshots/<идентификатор>/` и содержит manifest.json, postgres/*.jsonl, mongo/*.jsonl и assets-manifest.json. Статус копирования и статус удаления из рабочей базы фиксируются отдельно. Наличие копии не означает, что данные уже удалены.

Файлы снимков локальные и исключены из Git: они могут содержать исходные контекстные данные. README, индекс и инструмент экспорта остаются частью проекта. Это резервная копия на этом компьютере, не внешнее резервирование.

## Правила

- Не перезаписывать готовые снимки; создавать новый каталог.
- Сначала выгрузить данные, затем проверить SHA256, количество строк, формат и связи.
- PostgreSQL: сохранять описание типов и ключей вместе с JSONL. MongoDB: canonical Extended JSON, сохраняющий BSON-типы.
- Ссылки на изображения не являются копией самих файлов: assets-manifest.json описывает ссылки и ограничения.
- Удаление из источника — отдельная операция после проверки архива и переключения активных потребителей.
- Архив будущих рифтов/мира — отдельный снимок с явно заданным составом, не автоматическая выгрузка всего сервера.
