# The Sealed World / TurnBasedMMORPG

Браузерная пошаговая MMORPG. Этот репозиторий содержит серверные сервисы,
игровой клиент, каталоги контента, документацию и инструменты разработки.

## Установка и передача другому ИИ

Начните с [инструкции локальной установки](docs/ru/management/ai-local-setup.md).
Она разделяет чтение/работу с графикой, установку зависимостей и запуск
локальных сервисов. Production-доступ не нужен для изучения исходников.

Рабочая ветка — `develop`. Ветка `main` используется для production;
скачивание `main` не заменяет получение текущего снимка разработки.

```powershell
git clone --branch develop https://github.com/CodexDLC/thesealedworld.git
cd thesealedworld
```

Для загрузки без Git: [ZIP ветки develop](https://github.com/CodexDLC/thesealedworld/archive/refs/heads/develop.zip).

## Где лежат исходники

- `src/backend/` — игровые сервисы, каталоги предметов и боевых действий.
- `src/frontend/` — сайт, кабинет и игровой клиент.
- `src/shared/` — общие контракты.
- `src/tg_bot/` — Telegram-бот; для чтения каталогов запускать его не требуется.
- `assets/` — исходные художественные материалы и метаданные; подключённую
  графику клиента ищите по указателю CURRENT_GAME_UI.md.
- `tests/`, `tools/`, `docs/`, `tasks/` — проверки, инструменты и рабочая документация.

Наличие определения в каталоге не означает окончательный баланс или доступность
всей механики игроку. Концепции и проверенное поведение нужно различать.

## Что намеренно остаётся локальным

Корневые `archive/`, `output/`, `artifacts/` и промежуточные результаты не входят
в скачиваемый снимок. Автономная мастерская `output/rift-art-lab/` — отдельный
инструмент, а не часть установки игры. Готовые материалы художнику передаются
отдельно. Окружения, реальные настройки доступа, базы и кэши в репозиторий
не включаются.

Это снимок разработки, а не инструкция по выкладке на production. Публикация
ветки сама по себе не разворачивает приложение и не подтверждает готовность альфы.
