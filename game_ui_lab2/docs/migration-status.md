## Границы

Это работающий прототип нового клиента, ещё не замена старой лаборатории и не production-интеграция. game_ui_lab остаётся образцом. В src/game_client ничего не переносили, игровой frontend src/frontend не удаляли. Будущие замена папки, перенос и очистка требуют проверки и отдельного этапа. Коммит/push не выполнялись.

Vue владеет оболочкой, HUD, персонажем/инвентарём, квестами, сообщениями, ареной/кварталами и текстовыми концепциями. Phaser сохраняет отрисовку рифта/боя в одном canvas. Визуальные модули старой Lab преобразованы в ES modules с явными импортами, без запуска её boot.js и без Python/Jinja.

Локальные ассеты взяты из game_ui_lab и выбранных общих static-ресурсов src/frontend, изображения предметов — из assets/item_art/renders. Они скопированы в public; runtime не читает соседние проекты. Исходный ориентир — develop после принятия PR4, merge6da76145. Цвета и artwork сохранены. Текстуры рифта1024, ель512, reference crop преобразуется как прежде.

## Интеграции

- app/gameClient.js — сценарий загрузки через внедряемый gateway; integrations/mockGameGateway.js возвращает независимые копии fixtures и честное уведомление вместо реального надевания/крафта.
- integrations/mockChatGateway.js и mockCombatLogGateway.js — разные источники/подписки. Боевой поток останавливается вне combat; поля ввода у боевой вкладки нет.
- integrations/mockFieldGateway.js — готовые демонстрационные ответы смены визуального участника; клиент не вычисляет урон. Ресурсы HUD, боевые карточки и лог — независимые примерочные данные, не синхронизированный настоящий бой.
- features/places/constructionFixtures.js — готовые состояния вместо вычисления стоимости/прогрессии строительства. При переносе не копировался алгоритм construction.js старой Lab.
- Форматы инвентаря/персонажа здесь презентационные, не объявлены production API. Возможности backend необходимо сверять при интеграции; недостающие данные явно отмечать. Подключения backend/WS/реального движения нет.

## Оставшиеся ограничения

- Точное попиксельное совпадение всех состояний/разрешений и полноценный mobile UX не приняты владельцем; старую Lab пока сохраняем. Нативные HTML-элементы могут иметь отличия от Phaser-отрисовки.
- Модификаторы используют пользовательскую проекцию: профили оружия, общие прямые бонусы, отдельные боевые/мирные группы. Состав не равен всей схеме DTO; значения — готовые mock, не вычисленный актёр. Отсутствие диалогов квестов сохраняется.
- Унаследован спорный infill отдельной елью в forest C, не исправлялся в миграции стека.
- Поле боя и старые координаты панелей сохранены; дальнейшая доводка привязки панелей к углам обсуждалась, но отдельное изменение компоновки боя пока не выполнялось.
- Все моковые каналы доступны для примерки, охват Локации и торгового канала ещё не утверждён.
- Phaser загружается отдельным chunk около1.24MB (gzip335KB); Vite предупреждает о размере. Предупреждение не отключено, оптимизация не заявляется.
- Tauri, production hosting, реальные API/WS, полноценный рифт и удаление старого клиента пока не выполнялись.

Режим: исполнители Sol high/medium для изолированных компонентов, интеграция и проверка ведущим. Независимый ревизор не подключался (прежний выбор без ревизора). Автоподхват GEMINI конкретной средой не проверялся; корневые AGENTS/GEMINI теперь дают маршрут в Lab2 и старую Lab.
