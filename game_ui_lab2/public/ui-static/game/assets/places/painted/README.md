# Рисованные сцены мест

Версии владельца от2026-10-26. Оригинальные JPEG4096×2284 сохранены побайтно внеstatic: game_ui_lab/sources/places/painted/. Имена по назначению: arena-hall, administrative-quarter, trading-quarter, crafting-quarter, residential-quarter. Source-manifest хранит исходные имена иSHA256.

Runtime:1920×1071WebPquality86/method6, без изменения композиции. Генератор: tools/game_ui_migration/build_place_backgrounds.py. Каталог runtime manifest.json содержит dimensions/bytes/SHA256 и связь сmaster. Все5WebP:1 582 168bytes вместо23 236 786bytes JPEG (−93,2%). Один decodedRGBAфон:8 225 280bytes (~7,84МиБ). WebPснижает сеть/диск; уменьшение размеров снижает текстурную память.

Максимальная logicalширина общегоframe1920, status320, реальныйцентральныйhost~1597px сграницами (проверено приviewport2560). DPR влияет наbackingstore, а не компоновку; для нынешнего целевого набора экранов выбран единый1920pxфон.

Стиль: рисованное средневековое фэнтези, выразительные формы и тёплые фактуры камня/дерева, без прежнего глянца. Точный промпт переработки владельцем не предоставлен.

Путь игрока: город→конкретныйквартал→конкретноездание/помещение со своим фоном. Общего игрового меню выбора4кварталов нет. Каждый вход загружает только свою картинку, выход освобождает фонместа. Старые городские тайлы вLab освобождаются при входе в квартал; логическое положение маркера сохраняется при возврате. ОбщаяtoolbarLab — инструмент стенда и в игру не переносится. Отдельные картинки внутренних зданий пока не предоставлены, текущие вложенные панели — прежний прототип.

Механика, Backend, рифт и текущие хотспоты не менялись. Runtime-миграция сервисов вsrc отдельный этап. Прежние глянцевыеPNG и ихprompts находятся вarchive/game_ui_migration/2026-10-26/retired-place-art.
