## First composition brief
Exploration RPG, regular pointy 2.5D field; desktop mouse first, localized Russian labels. The decision is what to do with the chosen target, while direct adjacent movement stays fast. Existing character panel and chat remain authoritative shell.

Visual direction: small dark olive/brown round action buttons with restrained bronze edge, coherent line icons and short labels. Open center so target remains readable; a few meaningful buttons instead of a full decorative wheel. Focus/hover distinct, unavailable action has a reason. No new bitmap art needed.

Context: self-click opens own action cluster; visible entity or deliberate context-click opens target actions; ordinary empty-cell click still moves one step. Context menu offers real local preview actions only: inspect, adjacent move/approach, pending encounter test/retreat. Resource/chest/sanctuary actions not yet wired must be clearly unavailable with explanation, no fake reward or buff. Danger preview explicitly labelled test.

Menu follows world target under camera pan/zoom, flips/clamps within viewport and avoids target occlusion; click outside/Esc closes, controls own their input and prevent map click-through. No hidden-target information, no remote gather/fight. Routine feedback short-lived near edge/target; detailed messages in existing system chat, no repeated full-width movement notice. One unobtrusive help affordance replaces always-on long control strip.

Before implementation: create a runnable isolated composition/blockout or compare meaningful options; use this to decide exact dimensions. Final evidence must include actual game menu, edge placement, close/back and encounter preview interaction, not just screenshots of HTML standalone.
