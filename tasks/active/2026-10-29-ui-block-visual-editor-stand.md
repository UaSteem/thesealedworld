Задача: развернуть и собрать в лабораторном стенде игры полноценный интерактивный визуальный редактор (стилизатор) UI блоков, позволяющий на лету конструировать, настраивать, сравнивать и экспортировать визуальные стили игровых интерфейсных элементов (рамки, фоны, градиенты, свечения, скосы, виталы, слоты экипировки/инвентаря, боевые кнопки, плашки).

## Требования и ограничения

- [ ] **R1. Каталог игровых UI блоков (компонентов) для визуальной настройки**:
  Включает основные типы блоков игры The Sealed World:
  1. *Игровые панели и контейнеры* (окно персонажа, диалоговое окно, модальная рамка).
  2. *Слоты предметов и экипировки* (квадратные/squircle слоты 1–8 тиров редкости, бейджи, подложки).
  3. *Полосы ресурсов / Виталы* (HP, EN, CONC: стили 3D Glossy, Flat RPG, деления, бегунки, анимация).
  4. *Кнопки действий / Боевая колода* (основные действия удара/защиты, вторичные кнопки, состояния hover/active/disabled).
  5. *Информационные плашки и бейджи* (инспектор предмета, тултип, чипы очереди ходов, статусы).
  6. *Строки чата и боевого журнала* (системные оповещения, урон, фразы NPC).

- [ ] **R2. Интерактивная студия визуального стайлинга (Live Visual Styler)**:
  Панель управления с мгновенным откликом (live updates):
  - *Геометрия и рамки*: толщина границы (0–8px), стиль (solid, double, groove, металлический скос bevel, готический кант), скругление углов (border-radius) и фэнтезийные скошенные углы (cut-corners / clip-path).
  - *Фоны и градиенты*: базовый тон, многоточечные линейные и радиальные градиенты, угол падения света, текстуры/шум, прозрачность, размытие подложки (backdrop-filter: blur).
  - *Тени, объём и свечение (FX)*: внешняя тень (drop shadow), внутренняя глубина (inset shadow), неоновое/магическое свечение ауры (glow spread, blur, цвет).
  - *Типографика*: выбор шрифта (Cinzel, Inter, JetBrains Mono), размер, letter-spacing, text-shadow (золотое тиснение, контурная обводка).
  - *Декоративные элементы*: орнаменты углов, заклёпки, рунические акценты, маркеры редкости.

- [ ] **R3. Библиотека стилевых пресетов (Presets)**:
  Встроенные стили для моментального переключения:
  - 🛡️ *Noble Dark Fantasy* (обсидиан, состаренная латунь/золото, благородные самоцветы).
  - ⚡ *Acid Neon / Cyber-Rift* (глубокий индиго, неоновая бирюза, кислотные акценты).
  - 👑 *Imperial Gold* (зеркальная позолота, бархатный фон, рубины).
  - 🏛️ *Ancient Stone / Granite* (шероховатый камень, гранит, медь).
  - 🌌 *Abyssal Void* (черная пустота, призрачный эфир, фиолетовое свечение).
  + Сохранение и загрузка пользовательских пресетов через `localStorage`.

- [ ] **R4. Интерактивная витрина и режим инспектора (Showcase & Click-to-Inspect)**:
  - Стенд предпросмотра: отображение всех компонентов бок о бок с возможностью смены тестового фона (шахматка прозрачности, темный фон, текстурный игровой арт).
  - Клик по любому компоненту на витрине сразу активирует его редактирование в панели параметров.

- [ ] **R5. Экспорт параметров и интеграция в проект (CSS / Tokens)**:
  - Кнопка генерации и копирования готового CSS (CSS Custom Properties и классы) в буфер обмена.
  - Кнопка экспорта JSON структуры дизайн-токенов (согласована с дизайн-системой проекта).
  - Спецификация для верстки коллеги / разработчика.

- [ ] **R6. Изолированный запуск и доступность**:
  - Интеграция в лабораторный стенд `game_ui_lab` (доступен через HTTP-сервер на порту 8090).
  - Поддержка запуска на ПК и предпросмотра по локальной сети / со смартфона.
  - Не затрагивает production runtime и базу данных игры.

## Предположения и открытые вопросы

- Инструмент создается в рамках автономной лаборатории `game_ui_lab` с удобным bat-файлом запуска и веб-интерфейсом.
- Пользователь может выбрать: удобнее ли ему отдельная полноэкранная страница редактора (например, `ui_editor.html`) или интеграция в виде отдельной вкладки в уже существующий стенд с переключением на экраны игры. (Рекомендуется реализовать оба доступа: отдельный специализированный редактор + вызов из панели стенда).

## План реализации

1. Подготовить архитектуру редактора: HTML-разметку студии (`editor.html` / компонент стенда), структуру элементов и панель контролов (инпуты, слайдеры, колорпикеры, селекторы).
2. Реализовать CSS-переменные и динамический генератор стилей на клиенте (чистый JS без тяжелых зависимостей для мгновенного отклика).
3. Добавить библиотеку типовых игровых блоков The Sealed World (панели, виталы, слоты экипировки тиров I-VIII, кнопки умений боя, диалоговые плашки).
4. Реализовать пресеты (Noble, Acid, Imperial, Stone, Void) и механизм LocalStorage для пользовательских настроек.
5. Реализовать панель экспорта (Copy CSS, Copy JSON Tokens, Specs summary).
6. Связать с сервером `server.py` и протестировать в браузере (desktop и mobile).
7. Провести проверку в выбранном пользователем режиме.
