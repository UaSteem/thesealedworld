# Game UI Lab: новая компоновка

## Запрос и границы

Пользователь поручил переделать существующий game_ui_lab под обсуждённую компоновку. Сейчас не создавать скилл: сначала собрать и проверить интерфейс, затем определить закреплённые решения. Лаборатория должна запускаться и позволять художнику/агенту адресно менять окно персонажа, цвета и ассеты, сохраняя остальной интерфейс.

Рабочая область: game_ui_lab и необходимые относящиеся к ней проверки. Основной runtime src и rift_lab не менять. Не переносить демонстрационные действия в настоящую игру; не менять игровые данные. Не создавать альтернативный интерфейс вместо существующей лаборатории.

## Режим проверки

Пользователь выбрал обычную проверку: без независимого агента-ревизора, визуальная приёмка за пользователем. Работать небольшими изменениями; не тратить токены на отдельного ревизора. independent-review: not-requested.

## План

1. Прочитать актуальные точки входа, оболочку, сцены, данные и проверки лаборатории; уточнить переиспользование существующего окна персонажа и инвентаря.
2. Изменить существующую оболочку, добавить компактный HUD и меню; сохранить один Game/canvas и нижний чат.
3. Собрать единое окно персонажа из существующих компонентов, сохранив полезные сцены и поведение лаборатории.
4. Сделать понятные точки изменения цветов/ассетов и запуска, без скилла и параллельной копии интерфейса.
5. Проверить запуск, переходы, окно персонажа, resize, взаимодействия и соответствие R1–R10 в браузере; выбранная независимая проверка при наличии поручения.

## Следующее уточнение: полноценная страница персонажа

Открытая страница заполняет всю игровую область, без сжатого модального окна. Экипировка слева только у снаряжения. Характеристики объединяют асимметричные блоки атрибутов, всех навыков (закрытые с замком, открытые с процентами) и модификаторов. Отдельные Навыки/Эффекты убрать. Билды: не реализовано, под вопросом; не имитировать выбор. Квесты оставить. Согласованный локальный слепок вместо независимых чисел-заглушек; базовое оформление без дополнительной художественной проработки. Отдельного ревизора не запускать.


Уточнение меню: один блок Персонаж / Квесты / Настройки. Персонаж объединяет снаряжение и характеристики (атрибуты, навыки, модификаторы), возможные билды; эффекты убрать. Квесты — самостоятельная полноширинная страница с узким списком/статусами и широкой областью выбранного квеста (описание/диалоги). Настройки — самостоятельная страница без несогласованных функций. В бою недоступны. Диалоги в учебном слепке отсутствуют, показывать это явно.

Результат текущего шага: страницы заполняют игровую область; снята modal-семантика и ограничение ширины. У характеристик нет панели экипировки, используются данные character-data из одного локального JSON. Экспортированы 41 навык текущего каталога, 3 открыты, 38 закрыты в fixture; 9 атрибутов, modifiers=[] без выдуманных эффектов. Квестовые примеры перенесены в JSON, выбор списка меняет описание; записанных диалогов нет. Настройки и билды имеют честные состояния отсутствующей реализации. Проверено: 17 focused tests PASS, браузерный переход карта → квесты → персонаж, нет console errors. Обычная проверка ведущим, визуальная приёмка владельца pending.
