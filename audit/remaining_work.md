# Оставшиеся задачи

Актуализировано: 22.10.2026. Этот файл — основной краткий список незавершённой работы.
Выполненные шаги и доказательства остаются в [истории](plans/06_non_gameplay_hardening_progress.md).

Локальный инфраструктурный пакет прошёл [независимую ревизию](reviews/2026-10-22-infrastructure/final.md).
IR-01, IR-02 и IR-03 закрыты. Рабочий сервер этим не изменён.

| Пункт | Когда выполнять | Что осталось |
| --- | --- | --- |
| Рифты | Следующая предметная задача | Уточнить требуемое изменение перед реализацией. Инфраструктурная ревизия не проверяла игровую механику рифтов. |
| Три игровых сбоя тестов | До слияния в main | Два inventory-теста ожидают отсутствие `metrics`. Для `golem_foundry` отсутствует loot-профиль. Согласовать игровые контракты; не ослаблять проверки. |
| AG-05, адресная типизация | При подготовке слияния в main | Продолжить оставшуюся типизацию. Перепроверить актуальный объём, сохранить игровые правила. |
| Полный quality gate | До слияния и выпуска | Запустить общий gate, coverage и типизацию после игровых исправлений. Предыдущие адресные проверки не заменяют этот этап. |
| Чат alpha: A09-03/04/08/11 | Отдельный проект | Уточнить производительность архива, backpressure, Mongo projection и предел истории вкладки. Затем определить задачи. |
| Права хранилищ: A08-02 | При подготовке серверного применения | Проверить реальные роли, владельцев и права PostgreSQL/MongoDB, команды и ключи Redis. Подготовить credentials, проверку отказов и откат. |
| Восстановление и alerts: A08-15 | До выпуска | Согласовать расписание, retention, offsite и RPO/RTO. Проверить восстановление реального backup и доставку уведомлений. |
| Workflow, secrets и применение | Перед разрешённым выпуском | Перепроверить GitHub protections, область secrets и опубликованный workflow. Применить allowlists, проверить Studio token, HTTPS origin и smoke. |

Серверные действия собраны в [едином release-checklist](../docs/ru/management/infrastructure-release-checklist.md).
Production operations, commit, push и deploy требуют отдельного поручения.

Автоматический повтор игровых эффектов из Redis quarantine не разрешён.
Domain replay и межхранилищное восстановление требуют отдельного доказательства безопасности.
