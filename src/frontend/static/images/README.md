# Где находится актуальная графика

Текущий указатель: [CURRENT_GAME_UI.md](../../../../CURRENT_GAME_UI.md).

- `game-client/` — перенесённая графика нового игрового клиента.
- `game-client/places/` — актуальные paintedфоны помещений и кварталов.
- Боевой визуальный прототип: `game_ui_lab/static/game/assets/combat/` от корня проекта.

`exploration/terrain/`, `scenes/` и `game/arena/backgrounds/` — оставшиеся совместимые
зависимости старых/неперенесённых экранов, не референсы нового дизайна.
Неиспользуемые terrainкартинки выведены в archive/game_ui_migration/2026-10-27/retired-unused-terrain.
