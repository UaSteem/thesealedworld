# Сборка встреч по двум пулам

Заказ описывает одну семью, тир локации, тип встречи, сложность, режим, seed, необязательный GS игрока и полный profile_override. Теги остаются во внутреннем поиске.

`profiles/` — библиотека режим → тип → сложность. Профиль содержит независимые бюджеты `minions` и `seniors`, разрешённые ранги с минимумами и максимумами, общий лимит бойцов. Сборщик сначала оплачивает обязательных и дополнительных старших, затем заполняет оставшиеся места миньонами. Обязательного минимума миньонов нет; сохраняются общий минимум и максимум бойцов. Очки между пулами не переносятся. Миньоны используют относительный GS игрока к эталону тира с верхним капом; без GS такой заказ явно отклоняется. Старшие сохраняют отдельную ступенчатую добавку. Внешние fixed-профили по-прежнему могут работать без GS.

Обычная встреча содержит только миньонов; патруль требует ветерана, охрана элиту, главарь босса. Старый единый бюджет и точные варианты core не принимаются. Группа пока отклоняется. База, характеристики и Combat не изменяются.
