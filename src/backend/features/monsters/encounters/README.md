# Подбор встреч

`services/` подготавливает habitat pools и выбирает группу. `policies/` содержит правила состава и профили встреч, `resources/` — условия появления, `integrations/` — чтение контекста локации.

В следующей логике входом будут требования мира/рифта: условия окружения, уровень, сложность, ограничения и предпочтения. Результат — выбранные определения каталога и состав встречи. Создание нового вида или клана при подборе не предполагается.

Текущий MonsterGroupService ещё координирует подготовку actor snapshots и кеширование группы. Перенос папок не разделяет этот сервис автоматически; границу с instances нужно уточнить следующей задачей, сохранив нынешнее поведение до её реализации.
