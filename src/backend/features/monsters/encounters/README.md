# Подбор встреч

`dto/` содержит новые контракты подбора. `policies/` содержит правила состава и прежний автономный сборщик, `resources/` — условия появления, `integrations/` — чтение контекста локации. Старые `services/` подготовки habitat pools и сохранённых групп остаются отключёнными через границу retirement.

В следующей логике входом будут требования мира/рифта: условия окружения, уровень, сложность, ограничения и предпочтения. Результат — выбранные определения каталога и состав встречи. Создание нового вида или клана при подборе не предполагается.

Новая линия начинается с `MonsterSquadRequestDTO` и различаемого результата `MonsterSquadResultDTO`: выбранный полный состав либо явный отказ. Тир, количество и роли — обязательные ограничения; GS не является обязательным входом. Выборка кандидатов и проверка их готовности будут координироваться отдельным сервисом, а сборка бойца уже принадлежит `instances`. Подключение новых DTO к игровому runtime на этом этапе не выполняется.
