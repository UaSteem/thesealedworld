# Инспекция

`dto/` и `services/` предоставляют представления сохранённых кланов, бойцов, характеристик, оборудования и визуальных данных. `intel_projector.py` готовит проекцию сведений о монстре для потребителей.

Инспекция читает и представляет данные. Она не выбирает состав встречи, не меняет боевые правила и не заказывает изображения. Studio остаётся интерфейсом просмотра; её записывающие действия монстров отключены.

Расчёт экземпляра принадлежит `instances/services/instance_builder.py`. `MonsterEquipmentStatsService.preview` вызывает этот сборщик, а `present` оформляет уже полученный результат в строки, группы и технические данные прежнего HTTP-контракта. Самостоятельной сборки атрибутов, вещей и финтов в инспекции нет.

HTTP-входы и проверка доступа остаются в корневом `api/`. Служебная пересборка каталога относится к catalog, а не к этой части.
