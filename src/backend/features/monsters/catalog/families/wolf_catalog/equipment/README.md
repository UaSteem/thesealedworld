# Готовое природное снаряжение волков

11 членов базовой стаи × тиры 0–5: 66 комплектов, 264 предмета.
Данные в `prepared/<variant>/tier_<tier>.py` — сохранённые проекции ItemService.
Генерация не вызывается при импорте, чтении каталога или инспекции.

Каждый комплект сохраняет исходные четыре природных слота и роль волка.
`equipment_set_id = wolf_pack.<base_id>` идентифицирует локальный комплект;
исходные характеристики, навыки и базовые определения волков не изменены.
`generation.natural_key` ссылается на природные названия и описания в
`catalog/resources/equipment_mapping.py`; проекция предмета хранит механику,
а текстовые overrides запросов сохранены в manifest.json.

Проверка целостности:

```powershell
.venv/Scripts/python.exe tools/monsters/prepare_wolf_equipment.py --validate-only
```

Для проверки повторной генерации используйте отдельный новый `--output`.
Скрипт фиксирует PYTHONHASHSEED=0, seed каждого предмета и UUID5, не создаёт
DB/AI-клиенты и отказывается перезаписывать существующий каталог.
Ручные изменения допустимы; после ревью явно обновите хеши манифеста,
не запускайте генерацию поверх отредактированных данных.
