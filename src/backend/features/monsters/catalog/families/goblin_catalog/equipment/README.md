# Снаряжение гоблинов через общий каталог

`entries.py` и `sets.py` сохраняют предметные основы и слоты бойцов.
`references.py` назначает общие боевые профили и формирует ссылки на готовые предметы Т0–Т5.
`prepared_loader.py` разрешает ссылки в независимые экземпляры с владельцем комплекта. Генерации и БД при чтении нет.

Механика хранится только в `monsters/catalog/equipment_library/prepared/`. Для гоблинов это 138 общих определений, 72 комплекта и 282 назначения. Общий предмет не содержит имени вида и может быть использован другими видами, кланами и природным оформлением.

Названия, описания и природный ключ являются переопределениями ссылки, а не копиями механики. Подробности профилей, ограничений, подготовки и проверки: [общий каталог](../../../equipment_library/README.md).

Просмотр: `python tools/monsters/export_goblin_equipment_review.py`.
Проверка данных: `python tools/monsters/prepare_goblin_equipment.py --validate-only`.

Предыдущие полные копии комплектов сохранены в `archive/goblin_equipment_guidance/pre-shared-library/`. Активного резервного чтения оттуда нет. Характеристики основ и коэффициенты тиров не менялись; изменены только подготовленные предметы.
