# Общие предметы монстров

Этот каталог хранит готовую механику, общую для видов. Он использует существующие предметные основы, материалы и контракты модификаторов домена Items, не копирует их определения.

- `contracts.py`: определение общего предмета и ссылка слота с необязательным оформлением.
- `profiles.py`: явные боевые профили монстров. Это ручной контент, а не обычные пулы случайного лута игрока.
- `prepared/<profile>/<base_slot>/tier_N.py`: один предмет, один тир, стабильный ID. В данных нет владельца и принадлежности виду.
- `prepared/index.py`: индекс ID → модуль. Импорт и разрешение ссылки не генерируют предметы и не обращаются в БД.
- `manifest.json`: контрольные суммы сохранённых данных.

Вид назначает ссылки в своём `equipment/references.py`. При сборке создаётся независимая копия с устойчивым ID экземпляра и владельцем комплекта. Правка копии не меняет общий предмет. Название, описание и природное оформление можно задать на ссылке; механика при этом остаётся общей. При изменении механики нужен другой профиль/ID или явное обновление общего определения для всех пользователей.

## Первая коллекция: гоблины Т0–Т5

72 комплекта используют 138 определений в 282 слотах. Основы, слоты, навыки, роли, базовые характеристики и множители атрибутов гоблинов сохранены. Остальные виды пока читают свои прежние подготовленные комплекты.

Оружие получает точность соответствующей руки, крит и пробивание. Щиты — силу защиты, физическое сопротивление и HP. Подвижная броня — уклонение, броню, сопротивление и HP; тяжёлая не получает уклонение. Амулеты подбираются под физический билд. Нулевые результаты атрибутных аффиксов не сохраняются. Боеприпасы сохраняют основу и родные свойства без случайных аффиксов.

Исключены внебоевые свойства, неподтверждённые в resolver контроль/отражение, магическое нападение без способностей, EN/удача и лечение. Бонусы амулета к магической броне являются свойством существующей основы, а не аффиксом магического нападения.

Количество полезных аффиксов не раздувается до четырёх. Усиление сохраняет прежние правила монстров: 2/3/4/5/7/9 шагов на Т0…Т5 и материал `tier_mult`. Числа авторские средние, качество 50%, через существующую формулу ролла и компилятор Items. Поэтому эта коллекция не является случайным дропом игрока и не воспроизводит его ограничения слотовых пулов.

## Работа с данными

`python tools/monsters/prepare_goblin_equipment.py --validate-only` проверяет сохранённую библиотеку. Первичную подготовку или сравнение выполняют с `--output <новая папка>`; инструмент отказывается перезаписывать готовые данные. Он создаёт основу через ItemFactory без аффиксов, после чего применяет явный профиль существующим роллером/компилятором. Это только авторский инструмент, не путь сборки монстра.

`python tools/monsters/export_goblin_equipment_review.py` создаёт HTML, CSV и ссылки для просмотра без БД и боёв.

Предыдущие дублированные результаты и старый инструмент сохранены в `archive/goblin_equipment_guidance/pre-shared-library/`; они больше не читаются загрузчиком гоблинов.
